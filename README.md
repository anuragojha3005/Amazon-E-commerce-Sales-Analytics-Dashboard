# 🛒 Amazon E-commerce Sales Analytics Dashboard

## 📌 Overview

This project is an end-to-end **Data Analytics** solution built using **Python, SQL Server, and Power BI**. It analyzes **1 million Amazon e-commerce transactions** to uncover valuable insights into sales performance, customer behavior, returns, and logistics.

The project demonstrates the complete analytics workflow, from data preprocessing to interactive dashboard creation for business decision-making.
